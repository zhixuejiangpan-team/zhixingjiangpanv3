### 2.3 涂鸦笔触三规则（3D 建模必须遵守）

1. **手绘抖线（wonky）**：所有几何体顶点按点位种子做随机抖动，禁止绝对平直的边。抖动幅度 0.06–0.16 世界单位（按部件尺寸）。
2. **黑色墨水描边（ink outline）**：每个平涂部件外层包一个**倒置外壳（inverted hull）**——同几何体 `scale(1.045)`、`BackSide` 渲染、纯墨色 `#2B2620`，实现外描边。
3. **平涂着色（toon）**：`MeshToonMaterial + 3~4 阶渐变 map`（白 → #C8C8C8 → #7F7F7F → #3F3F3F，NearestFilter 硬过渡），无平滑渐变、无 PBR 写实贴图。糙度 0.9。

## 3. 3D 数字孪生系统（js/twin3d.js）—— 核心规格

### 3.1 总览

- 入口：`window.Twin3D.open(opts)`；`opts = { name, type, kind, id, getState() }`。
- `getState()` 每帧返回 `{ p: 0..1 拥挤度, n: 人数, level: 'green'|'yellow'|'red', cap: 容量 }`。
- 单例查看器：同一时刻只允许一个；关闭时**完整释放**（geometry/material/texture dispose + `forceContextLoss`）。
- 能力检测：`WebGL2 || WebGL`；`?no3d=1` 可强制禁用。

### 3.2 渲染与场景

| 项 | 参数 |
|---|---|
| Renderer | `WebGLRenderer({ antialias: true, alpha: true })`；`setPixelRatio(min(devicePixelRatio, 2))`；`localClippingEnabled = true`（剖面用） |
| 阴影 | `PCFSoftShadowMap`，主方向光 1024×1024 shadow map（低端机关闭） |
| 相机 | `PerspectiveCamera(45°, near 0.1, far 200)`，初始位 (14, 12, 18) |
| 控制 | OrbitControls：`dampingFactor 0.06`；极角 20°–85°；距离 8–40 |
| 环境反射 | PMREMGenerator + 六面 Box 环境贴图（色板：天空蓝 #8FB8FF ×2、灰白 #E8ECEF、沙黄 #C9B58E、暖橙 #FFD9A0、粉 #FFB0C0），`fromScene(..., 0.04)` |
| 雾 | `Fog(白天 var(--bg), 30, 80)`；夜间渐变为 `#02040A` |
| 灯光 | 主平行光 `#FFFFFF` 强度 1.15，位 (10,16,8)，开阴影；环境光 0.5；主题色点光（accent，强度 10，范围 30，位 (0,0.6,0)） |
| 灯光昼夜 | 夜间：主光 ×(1−0.45)、环境光 ×(1−0.25)、自发光材料 ×(1+1.3)；雨/雪：×0.8 |
| 底座 | `CircleGeometry(8.4, 48)`，MeshStandardMaterial（颜色=状态色、emissive 同色 0.4、roughness 0.5、metalness 0.2、opacity 0.9），平铺地面 y=0.01 |
| 光晕 | `RingGeometry(8.4→10.4, 48)` 同色呼吸：4 秒周期 0.55→1.18→0.55 缩放，透明度 0.28×(1.2−s×0.45) |
| 接触阴影 | 256×256 径向渐变 CanvasTexture（中心 rgba(0,0,0,0.5) → 0.55 处 0.15 → 透明），17×17 平面铺底，模拟 AO |

### 3.3 建模语言（每个部件的构成法）

```
part(parent, geometry, color, opts) =
    Group {
      主体: MeshToonMaterial(color, gradientMap=toonGradient, roughness 0.9)
      描边: 同几何体 clone, MeshBasicMaterial(INK #2B2620, BackSide), scale 1.045
    }
```
- 所有 Box/Cone/Cylinder 先过 `wobbleGeo(geo, amt, rand)`：每顶点加 ±amt/2 随机偏移并重算法线。
- 种子随机：`hashSeed(id)`（FNV-1a）→ `mulberry32`；`v = { hs: 0.85–1.25, ws: 0.85–1.2, accent: 随机撞色 }`——**同一建筑每次打开外观一致（确定性）**。

### 3.6 实时数据可视化（人流系统）

#### 3.6.1 涂鸦小人粒子（物理系统）

- 贴图：Canvas 64×64 手绘小人（头=填充圆 r10 + 手绘双圈描边 #26221B 3px；身体=六条 3px 线条），颜色随状态：green=#12A36B / yellow=#FFB000 / red=#FF3B5C。
- 数量：`MAX_P = 60`（低端机 0）；**拥挤度 > 60% 才出现**，实际绘制数 = min(60, floor(pct/2))。
- 材质：`PointsMaterial({ size 1.15, alphaTest 0.1, sizeAttenuation, depthWrite false })`。
- 物理（每帧 `dt ≤ 0.05`）：
  - 重力：`vy -= 9.8·dt`
  - 风力：`vx += sin(now·0.001)·0.9·dt`
  - 地面反弹：y < 0.3 时 `vy *= -0.4`
  - 活动半径 6.5（出界拉回并反向 ×0.3）
  - 两两碰撞：距离 < 0.6 时对称推开（O(n²)，n≤60）

#### 3.6.2 门口人流流动线

- 12 个点，沿二次贝塞尔 `P0(0,0.5,5.2) → P1(0,1.4,8.5) → P2(2.6,0.5,10.5)` 循环。
- 速度 `0.25 + pct/100·0.85`；点大小 0.34，颜色随状态；带 `sin(t/300+i)·0.15` 上下浮动。

#### 3.6.3 手绘计数牌

- Canvas 256×128：双圈抖线椭圆边框（墨线 4px）→ 蜡笔大数字（54px Comic Sans，状态色填充+墨描边，随机 ±0.06rad 倾斜）→「人 · 实时」小字。
- 挂载：Plane 3.2×1.6，位 (−5.4, 2.4, 2.2)，绕 Y 0.5。
- 人数变化瞬间弹跳：`scale = 1 + signPop·0.25`（signPop 1→0 衰减，2.4/s）。

### 3.7 状态语义（拥挤度 → 表现）

| 状态 | 阈值（p = n/cap） | 视觉 |
|---|---|---|
| green | p ≤ 0.6 | 底座/光晕/小人绿色；建筑静止 |
| yellow | 0.6 < p ≤ 0.85 | 黄色 |
| red | p > 0.85 | 红色；建筑 Y 轴呼吸 `1 + 0.01·(1+sin(2πt/3s))` + 每 100ms 随机 ±0.012 水平颤抖（低端机关颤抖） |
| 入场动画 | — | 300ms 内模型 0.6→1.0 弹性放大（`1-(1-k)³`）+ 全材质透明度 0→1 |

### 3.9 性能红线（3D 优化必须遵守）

1. **单一渲染循环**：查看器只用一个 RAF；关闭即 `cancelAnimationFrame`。
2. DPR ≤ 2；低端机（`hardwareConcurrency ≤ 4 || deviceMemory ≤ 4`）关闭：阴影、小人粒子、爆星、红态颤抖。
3. `prefers-reduced-motion`：入场动画瞬时、道具/呼吸动画全停、爆星禁用。
4. 几何预算：单建筑全部部件为低面数（Box 6 面、Cone 4–7 面、Circle 48 段、Ring 48 段）；**禁止高模**，细节靠贴图与描边表达。
5. 关闭时 dispose 所有 geometry/material/map/gradientMap，`renderer.forceContextLoss()`，DOM 移除，`body.overflow` 复原。
6. 纹理全部为程序化 Canvas 生成（无外部贴图资源）。

## 4. 地图 3D 层（高德 JS API 2.0 + Loca 2.0）

### 4.1 主地图（2.5D）

| 项 | 参数 |
|---|---|
| 初始 | center 蛟桥园、zoom 16.5、`viewMode: '3D'`、pitch 50°、rotation −15°、zooms [3,20] |

| 合规 | 主地图容器无圆角裁切，高德 logo/版权可见 |

### 4.2 Loca 呼吸点（三带）

- 3 个 `Loca.ScatterLayer`（zIndex 116），按拥挤度分带：green（≤60%）#12A36B / yellow（60–85）#FFB000 / red（>85）#FF3B5C。
- 点贴图 = Canvas 32 帧扩散光晕（halo 半径扩张 + 淡出），呼吸频率 **0.35Hz（空）→ 0.8Hz（满）**，周期 1.25–2.9 秒（缓慢扩散，非闪烁）。

## 9. 给 AI 3D 建模软件的优化方向（建议清单）

1. **建筑种类扩展**：现有 5 类 builder 覆盖食堂/运动场/图书馆/快递/医院，其余 59 个点位（学院楼、宿舍、办公楼等）用 fallback 或不可建模。优先新增：学院楼（多层窗格 + 院牌）、宿舍楼（阳台阵列 + 晾衣杆）、行政楼（大厅 + 台阶 + 校徽）。
2. **部件几何复用**：台阶/窗户/旗杆/树已在多处重复，建议抽为共享部件库（保持种子抖动差异化）。
3. **模型复杂度预算**：单建筑保持 ≤ 3000 三角形、部件数 ≤ 40；描边用倒置外壳（不增加三角形层级），保持现方案。
4. **材质统一性**：一律 MeshToonMaterial + 3~4 阶渐变；新增色不得超出「四色马克笔 + 六色 ACCENTS 撞色板」（#FF3B5C #2E6BFF #FFB000 #12A36B #8A6FD1 #3FA8B4）。
5. **物理粒子上限**：小人粒子 ≤ 60（低端机 0），保持 O(n²) 两两碰撞的预算内。
6. **夜景方案**：现为灯光/雾强度插值；可增加窗灯随机点亮（已有 `randomizeWindows/dayWindows` 概念位）作为夜间辨识度优化。
7. **剖面优化**：现用水平裁剪平面 y=2.6；可换为逐楼层模型（每层独立 Group）以便按层剖切与楼层导览联动。
