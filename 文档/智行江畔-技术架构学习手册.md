## 第 0 章 怎么开始读代码

### 0.1 运行方式

1. **直接双击 `index.html`**（file:// 协议）——设计目标就是零依赖直开，Three.js 用本地 vendor 保证可开。
2. 更推荐用本地静态服务器（避免 file:// 下摄像头等权限受限）：
   ```bash
   npx serve .        # 或 python -m http.server 8000
   ```
3. AI 问答需要代理：本地跑 `node server.js`（设环境变量 `DEEPSEEK_KEY`），再把 `js/config.js` 的 `AI_CONFIG.PROXY_URL` 改成 `http://localhost:3001/ai`；不配则 AI 卡片提示"未配置"，本地知识库搜索不受影响。

### 0.2 调试技巧

| 操作 | 效果 |
|---|---|
| F12 → Application → localStorage | 看所有 `zxsj66_*` 数据 |
| `localStorage.clear()` 后刷新 | 回到"首次访问"（重看开屏引导、地图开场） |
| URL 加 `?no3d=1` | 强制禁用 3D（模拟低端机） |
| 控制台 `ZXSJ.Themes.set('neon')` | 切主题 |
| 控制台 `ZXSJ.DataSource.getCrowd('ml_yst', 720)` | 查某点位拥挤度 |
| 控制台 `Twin3D.open({...})` | 直接开 3D 查看器 |
| `window.goTo('twin')` / `window.page(1)` | 跳章 / 翻页 |

### 0.3 关键全局变量

- `window.spots / hotQuestions / workflows / LINK_EDGES` —— 数据（data.js）
- `window.AIService` —— AI（ai-service.js）
- `window.ZXSJ` —— 挂载各子模块：`Themes`、`Gestures`、`Scene`、`DataSource`
- `window.Twin3D` —— 3D 查看器（twin3d.js）
- `window.goTo(name)` / `window.page(dir)` —— 导航
- `window.NARRATIVE_CONFIG` —— 章节顺序

## 第 1 章 项目总览

### 1.1 一句话

纯静态单页应用，用**涂鸦手绘风**把「搜问题、看地图、办事情、查人流」做进四个竖屏章节；**所有用户数据只存浏览器 localStorage**，唯一的后端是 DeepSeek 的 Serverless 代理。

### 1.2 技术选型全景（每个库"为什么选它"）

| 技术 | 用途 | 选型理由 |
|---|---|---|
| 原生 HTML/CSS/JS | 全部 | 零构建、file:// 直开、大赛演示不依赖环境 |
| 高德 JS API 2.0 | 2.5D 地图 | 国内合规地图 + `viewMode:'3D'` 免自建底图 |
| Loca 2.0 | 地图数据可视化 | 高德官方，呼吸点/事务链图层 |
| Three.js r147（本地） | 3D 孪生建模 | UMD 本地化，零 CDN 依赖；涂鸦卡通风 |
| D3 v7 | 力导向图 | 力模拟（charge/link/collide）+ zoom/drag 成熟 |
| ECharts 5 | 问卷图表 | 柱状/雷达快速出图（饼类已自绘多边形图替代） |
| MediaPipe Hands（CDN） | 可选摄像头手势 | 官方 UMD，惰性加载 + 多源回退 |
| DeepSeek（deepseek-chat） | AI 问答 | OpenAI 兼容，服务端代理持有 Key |
| 站酷快乐体 | 标题字体 | 手绘感；Google Fonts 加载，失败回退楷体/圆体 |

### 1.3 架构哲学（三条主线）

1. **纯静态 + 无后端数据**：用户隐私数据不下服务器，是隐私与成本的取舍。
2. **单一渲染循环**：3D / 粒子 / 力导图各引擎挂起-恢复联动，省电。
3. **确定性 + 降级链**：3D 建模用 spotId 做种子（同建筑每次一样）；移动端/低端机/reduced-motion 逐级砍特效。

## 第 3 章 加载与启动顺序

### 3.1 `<head>` 关键点

1. 首屏前**同步设定 `data-theme`**（防闪烁）。
2. 高德安全密钥 `window._AMapSecurityConfig`。
3. 依次加载 AMap、Loca、D3、ECharts、three、字体、style.css、intro.css。

### 3.2 `<body>` 末尾脚本顺序（依赖关系）

```
config.js → data.js → guide-data.js → survey-data.js
→ data-source.js → ai-service.js → themes.js → gestures.js → scene-fx.js
→ app.js（主程序，读取上面所有全局）
→ twin3d.js（THREE 未加载则 Twin3D 不定义，按钮置灰）
→ intro.js（开屏引导，检查 zxsj66_intro_done）
```

> 关键：**数据层先行**，`app.js` 依赖 `spots/hotQuestions/AIService` 等全局；`twin3d.js`、`intro.js` 最后，可独立拔插。

### 3.3 app.js 启动流程

1. 定义 `RM / FINE / MOBILE` 降级开关、`LS` 存储键常量、`cssVar/load/save/esc/toast` 工具。
2. 叙事引擎：绑定 snap 容器滚轮翻页、键盘、`IntersectionObserver` 段落激活。
3. 设置抽屉、搜索×AI、力导向图、地图、孪生、问卷、指南、融合、知识库、音效模块依次初始化。
4. 末尾 `boot` 段：`renderHist(); renderHot(); renderMineVotes(); renderMineHist();` 等首屏渲染 + 手势/主题/引导按钮绑定。

### 3.4 事件总线（跨模块通信）

| 事件 | 派发方 | 消费方 | 载荷 |
|---|---|---|---|
| `zxsj:progress` | 叙事引擎（滚动） | 各章生长动画 | `{ chapter, progress, all }` |
| `zxsj66:theme-change` | themes.js | 地图/力导图/孪生/光标 | `{ theme }` |
| `votesUpdated` | 投票 | renderHot / 我的投票 | — |
| `twin:status-update` | 孪生模块 | twin3d 底座颜色 | `{ id, color, crowdLevel }` |

## 第 4 章 核心模块详解

### 4.1 叙事引擎（app.js 顶部）

- **章节**：`NARRATIVE_CONFIG.sections = ['ask','map','twin','guide']`，四章各自 `<section class="sec">`，容器 `#snap`。
- **翻页**：桌面滚轮 → `innerScrollable()` 判定内层滚动区 → 否则 `page(dir)`；键盘 ↑↓/PgUp/PgDn/Home/End。
- **激活检测**：`IntersectionObserver`（root=snap，threshold 0.55）→ `onSectionChange(name)` 做引擎挂起/恢复（地图 Loca、孪生定时器）。
- **章内进度**：V9 为 snap 翻页，进度恒 1；每章 `.reveal` 元素进入视口淡入。
- **转场**：`playTransit()` 墨迹扫屏；`ShardArt` 背景碎片每章重组（Species in Pieces 手法）。

### 4.2 搜索 × AI（app.js「搜索 × AI」段）

流程：`searchInput 输入 → __renderSuggest 联想 → runSearch(q) → pushHist → renderResults → __renderRelatedCards → AI 回答`。

- `runSearch`：去重入历史（容量 50）、本地匹配渲染结果、纸飞机动画、展开结果浮层。
- AI：`scheduleAI`（防抖）→ `AI.callAI` → `aiState('success')` 渲染 AI 卡（含点位跳转按钮）。
- 安全链路见第 7 章。

### 4.3 力导向图（GraphModule，D3）

- 数据：`hotQuestions` 节点，`buildLinks` 按共享 `relatedSpotIds` 连边。
- 力：`forceManyBody(-170)` + `forceLink(distance 90)` + `forceCollide` + `forceCenter` + 自定义 `force('mouse')` 风力推开。
- 交互：拖拽（拉长回弹 `d3.easeElastic`）、滚轮缩放、点击节点**碎裂**成 6 片多边形再弹详情卡。
- 涂鸦风：墨线外圈 + 四色内圈、虚线分色、跨校区星标。
- 降级：FPS<30 自动切列表模式。

### 4.4 地图（MapModule，高德 + Loca）

- `new AMap.Map('mapBox', { viewMode:'3D', pitch:50, rotation:-15, zoom:16.5 })`。
- 楼块体量：`AMap.Buildings`（heightFactor 2.0，主题换色）。
- Loca：3 个 `ScatterLayer` 呼吸点（拥挤度三带）+ `LinkLayer` 六条事务链 + 开场相机动画（仅首次，`zxsj66_mapintro`）。
- 关联线：点某个点位 → 高亮相关点位连线（`drawRelatedLines/spotNeighbors`）。
- 手势导航：`syncGestureSupport` 轮询 `ZXSJ.Gestures.latest()` 平移/缩放。

### 4.5 数字孪生（TwinModule + twin3d.js）

- 数据：`DataSource.getCrowd(spotId, nowMin)` 高斯曲线模拟拥挤度（早/中/晚峰），返回 `{ p, n, level, cap }`。
- 展示：左列表实时人数 + 四张小地图 + 时间轴；点「3D」→ `Twin3D.open({ kind, getState })`。
- 3D 建模：见规格书第 3 章（五类建筑 + 涂鸦道具 + 小人物理 + 计数牌 + 剖面 + 手势）。

### 4.6 问卷（survey 段）

- 双口径：真实 34（唯一对外引用）+ AI 模拟 75（角标「含AI模拟样本」）。
- 视觉：大数字滚动计数、痛点排行榜马克笔条形、饼类自绘多边形面积图、其余 ECharts 柱状。
- 切换：手绘开关（`zxsj66_survey_view`）；数据源溯源区在最底部（真实 34 明细）。

### 4.7 指南（initGuide + fusion）

- 三页签：办事流程（workflows）、校历、医保指南；搜索框过滤卡片。
- `fusion`：把搜索结果与办事流程/医保做 Dice 相似度去重与跳转联动。

### 4.8 主题系统（themes.js）

- 三主题 token 定义在 style.css `html[data-theme="..."]`；切换只改 `data-theme` + 广播事件；模块按需换肤（地图深色样式、楼块色、光标、力导图色）。

### 4.9 手势（gestures.js）

- 惰性加载 MediaPipe（多 CDN 回退）；`classify` 输出 `{ point, pinch, fist, palm, dx, dy }`；HUD 预览；地图/3D 两处消费。

### 4.10 天气粒子（scene-fx.js）

- `ZXSJ.Scene`：雨夜/雪天/晴空场景切换 + 主地图 `.fx-overlay` canvas 粒子 + 闪电/积雪；单一 RAF。

### 4.11 底栏 Dock（V10.3）

- `#dock` 卡片，两标签「热点榜/我的足迹」；收起 Top5/最近 8 条，展开 `max-height:320px` 内部滚动；历史容量 50；切换标签自动回收起态。

### 4.12 开屏引导（intro.js）

- `zxsj66_intro_done` 不存在才播；四段（迷茫碎片→问号 / 探索校区轮廓生长 / 掌控 3D 卡片折叠 / 成长徽章证书）；单次滑动触发、动画期锁定；ESC/跳过随时退出；设置「重看引导」清标记。

## 第 5 章 数据层

### 5.1 localStorage 键全表（前缀 `zxsj66_`）

| 键 | 内容 | 敏感度 |
|---|---|---|
| `zxsj66_hist` | 搜索历史（≤50 条） | 低 |
| `zxsj66_aichat` | AI 对话历史（≤10 条） | **中**（明文） |
| `zxsj66_votes/voted/counts` | 投票与计数 | 低 |
| `zxsj66_realdata` | 导入的实测人流 JSON | 中（若含真实数据） |
| `zxsj66_weather` | 天气 30min 缓存 | 低 |
| `zxsj66_docs` / `doc_seen_<id>` | 文档更新红点 | 低 |
| `zxsj66_theme/gesture/survey_view/mapintro/intro_done/demo_scene/twin_demo/mute/easter` | 偏好/状态 | 无 |

### 5.2 静态数据文件结构

- `spots`：`{ id, name, campus, area, lng, lat, type, tags, votes, rating, floors? }`，共 64 个校内点位（麦庐/蛟桥/枫林）。
- `hotQuestions`：`{ id, question, category, tags, campusScope, isSensitive, relatedSpotIds, answers }`。
- `workflows`：`{ id, title, campusScope, estimatedMinutes, steps[] }`；`extraWorkflows` 补充。
- `LINK_EDGES`：六条事务链 `{ id, label, color, path: [spotId...] }`。

### 5.3 双源策略（data-source.js）

`getCrowd`：有实测数据（`zxsj66_realdata`）→ 返回 real；否则返回纯函数模拟。容量口径统一（食堂 150+tags·30、图书馆 800…），状态阈值 `p≤0.6 green / ≤0.85 yellow / else red`。

## 第 6 章 设计系统

### 6.1 涂鸦令牌与主题

见规格书第 2 章：纸底 `#FEFBF6`、墨线 `#2B2B2B`、四色马克笔、三主题 token、`--doodle-border/shadow/radius`、站酷快乐体。

### 6.2 手绘抖线滤镜（SVG）

```html
<filter id="doodleWobble">      feTurbulence + feDisplacementMap（scale 4）
<filter id="doodleWobbleStrong">scale 7（更强抖边）
```
`[data-doodle]` 标题、贴纸、气泡、3D 计数牌等引用 `filter: url(#doodleWobble)`。

### 6.3 动画原则

- 缓动统一 `--ease: cubic-bezier(0.34,1.56,0.64,1)`（回弹感）。
- 微交互 ≤200ms、转场 ≤700ms；呼吸动画周期 2–4s；发光**慢速扩散**（禁止快速闪烁）。
- `prefers-reduced-motion`：全站动画瞬时（`animation/transition: none`）。
- z-index 层级：背景 0 < 地图 100 < 孪生 200 < AI/联想 300 < 圆点 330 < 侧栏 340 < 转场/设置/抽屉 350–360 < 彩蛋 400 < 3D 500 < Toast 600 < 光标 900 < 开屏引导 1000。

| 层 | 机制 | 位置 |

## 第 8 章 学习路径与练习

### 8.1 建议阅读顺序

1. `config.js` → 2. `data.js`（看数据长啥样）→ 3. `app.js` 顶部叙事引擎 → 4. `app.js` 搜索×AI 段 → 5. `MapModule` → 6. `TwinModule` + `data-source.js` → 7. `twin3d.js` → 8. `ai-service.js` → 9. 其余小模块 → 10. `intro.js`。

### 8.2 10 个动手练习

1. 给 `hotQuestions` 加一条问题，验证首页热点榜与力导图都出现。
2. 在 `data.js` 加一个新点位（含 lng/lat），刷新地图看是否出现。
3. 改 `THEME_CONFIG` 加第四个主题，观察主题系统如何联动。
4. 调 `getCrowd` 的高斯曲线参数，看孪生人数随时间变化。
5. 给 `twin3d.js` 的 canteen builder 加一个新部件，看描边/抖动是否自动生效。
6. 在 `LINK_EDGES` 加一条事务链，看地图六链图例与流动线。
7. 改 `renderHot` 的排序逻辑，验证榜单实时重排。
8. 给 survey-data 加一道题，看 ECharts/多边形图自动渲染。
9. 用 `localStorage` 模拟"已看过引导"，验证 intro.js 跳过逻辑。
10. 加一个自定义 `CustomEvent`，在控制台监听 `zxsj:progress` 观察滚动进度数据。
