# 智行江畔 · 3D 建模优化提示词（第一版）

> 投喂对象：AI 3D 建模软件（或 3D 美术执行者）
> 配套文档：《智行江畔-全站架构与3D建模规格.md》（含全部现有参数、尺寸、配色，本提示词与其冲突时以本提示词为准）
> 目标：优化「界面内所有可建模的地方」，向以下两个参考作品的设计语言再靠近一步：
> - Make Me Pulse 2019：https://2019.makemepulse.com/
> - Species in Pieces：http://www.species-in-pieces.com/#

---

## 一、角色与总目标

你是「智行江畔」的 3D 美术总监。请对本站全部可建模元素做一次风格升级，**不改变任何功能与交互逻辑**，只优化建模与视觉表现：

1. **更「活」**：向 makemepulse 2019 的活物感靠拢——所有物体要有呼吸、弹性、摇摆、跟随鼠标的拟生感。
2. **更「碎」**：向 Species in Pieces 的碎片美学靠拢——能用多边形碎片拼出来的形体，就不用完整实体；聚合/碎裂转场作为第一视觉语言。

## 二、两个参考作品 → 可执行设计规则

### 2.1 取自 Make Me Pulse 2019（手绘涂鸦 + 高饱和 + 活物感）

| 规则 | 执行标准 |
|---|---|
| 白纸舞台 | 场景底 = 纸色 #FEFBF6（或主题 --bg），物体像"贴在纸上"；接触阴影是纸上的一滩淡墨，不是写实投影 |
| 马克笔描边 | 每个形体必须有 2–3px 墨色外轮廓（#2B2620/#2B2B2B），轮廓线条允许轻微"没画圆"的抖动 |
| 高饱和平涂 | 填充色只用：荧光粉 #FF2E63 / 电光蓝 #08D9D6 / 亮黄 #F9ED69 / 草绿 #6BCB77 + 六色撞色板（#FF3B5C #2E6BFF #FFB000 #12A36B #8A6FD1 #3FA8B4），禁止渐变与写实纹理 |
| 卡通光影 | 3–4 阶硬过渡的 toon 着色（NearestFilter 渐变 map），光影是"色阶"不是"过渡" |
| 拟生动画 | 物体按正弦呼吸（周期 2–4s，幅度 1–3%）；被点击/靠近时弹性缩放（回弹过冲）；道具（旗/星/云）持续漂浮 |
| 涂鸦道具 | 云朵、星星、纸飞机、铅笔、橡皮等文具作为场景配角，出现在模型周围 |
| 蜡笔字 | 数字与标签用蜡笔手写质感（Comic Sans / 站酷快乐体 + 抖动 + 墨描边） |

### 2.2 取自 Species in Pieces（多边形碎片 + 聚合叙事）

| 规则 | 执行标准 |
|---|---|
| 碎片即形体 | 主要形体由 8–20 片 `clip-path` 多边形（三角形/四边形/不规则五边形）**拼合**而成，碎片之间有 1–2px 纸色缝隙（"拼图感"） |
| 聚合与碎裂 | 形体出现 = 碎片从四周飞入聚合（600–900ms，错峰 40–80ms/片）；形体消失 = 碎片炸开飞散 |
| 碎片颜色 | 同一形体的碎片可用 2–3 种相邻色（如粉+黄），使拼合体有"色纸拼贴"感 |
| 情绪渐变背景 | 每个场景一个主色晕染（radial-gradient 低透明度），随章节切换变色 |
| 稀缺而明确 | 碎片数量克制（≤ 50/场景），每一片都要"看得清"，不堆粒子 |

### 2.3 融合公式（本站统一风格）

> **纸底 + 墨线描边 + 高饱和平涂 + 多边形碎片拼合 + 拟生动画 + 蜡笔字**
> 一句话：*「用彩色碎纸片拼出来的、会呼吸的马克笔涂鸦世界」*

## 三、优化对象清单（界面内所有可建模的地方）

### A. 五类建筑模型（js/twin3d.js BUILDERS）—— 核心优化

#### A1. 食堂 canteen
- 主体改用**碎片拼合外衣**：前立面由 6–8 片多边形色纸拼成（奶油底 #F6E7C8 上拼 粉/黄 色块），拼缝 1.5px。
- 屋顶四棱锥加粗墨线，尖顶插 1 面涂鸦小旗。
- 烟囱顶部冒**手绘烟圈**（3–5 个渐大的椭圆 Sprite，慢速上浮循环）。
- 发光窗 10 扇 → 增加"窗内小人剪影"（2–3 扇随机出现）。
- 门口雨棚改条纹遮阳篷（accent 色 + 白条纹）。
- 招牌：蜡笔字「食堂」挂在雨棚下。

#### A2. 运动场 stadium
- 跑道环保留圆环几何，但**表面用 6 片多边形色纸覆盖**（砖红 #D65A72 深浅两片交替）。
- 草坪改碎片草皮（草绿 + 亮黄碎片拼合，拼缝可见）。
- 看台加上**2–4 个小人观众**（静态贴图小人）。
- 篮板加白色涂鸦网（2–3 条交叉虚线）。
- 天空加 1 朵 makemepulse 式云（纸白 + 墨线）。

#### A3. 图书馆 library
- 幕墙竖条改**碎片玻璃**：9 条变 7 片不规则四边形（#8FB6D9/#9FD4C8 两色拼合，opacity 0.75）。
- 三层退台加"书脊装饰行"（一排 6–8 本彩色小书 Box，书脊色随机撞色板）。
- 顶部加 1 个旋转星 + 1 面旗。
- 台阶旁加 1 棵涂鸦树（已有道具复用）。

#### A4. 快递站 express
- 主体墙面拼 2–3 片色纸。
- 货架上的快递盒改为**堆叠纸箱山**（5–8 个随机旋转小盒，撞色板随机）。
- 门头招牌改蜡笔字「快递」+ 胶带斜贴（亮黄半透明矩形）。

#### A5. 校医院 hospital
- 红十字改**手绘十字**（两条末端圆头的胶囊几何）+ 呼吸发光（自发光 0.6→1.0，3s 周期）。
- 门前加 1 个药瓶道具（白瓶身 + 粉盖 + 蜡笔十字标）。
- 墙面加 1 条亮黄"爱心"涂鸦。

#### A6. fallback 兜底模型 → 扩展为三类通用建筑（新增，不改变 kind 映射）
- **学院楼**（默认）：w=6·hs 多层盒 + 3×4 窗格阵列 + 院牌蜡笔字条 + 旗。
- **宿舍楼**：细长盒 + 阳台小凸台阵列（3×5）+ 晾衣杆横线 + 被子色块。
- **行政楼**：宽扁盒 + 中央门厅凸出 + 3 级大台阶 + 圆形校徽（黄色碎片圆盘 + 墨线）。
- 仍无法归类时保持原 fallback 双盒。

### B. 涂鸦道具（旗/星/树 → 升级）
- **云**（新增，makemepulse 标志）：由 3–4 个重叠椭圆纸片 + 墨线组成，漂浮 + 跟随鼠标视差。
- **星**：改 6–10 角随机星形，增加"手绘未闭合"变体（一笔画星星，开口 10–20°）。
- **旗**：旗面改波浪形平面（4 段折面）+ 飘动动画保持。
- **树**：树冠改 3–5 片多边形碎纸拼合（两色绿），替代正二十面体。

### C. 场景舞台（底座/光晕/接触阴影）
- 底座圆盘 → **多边形碎纸盘**（12 片拼合的扁多边形，碎片间纸色缝），颜色 = 状态色，碎纸片可整体缓慢旋转（6s/圈）。
- 光晕环 → **手绘虚线双圈**（Canvas 贴图，虚线沿圈滚动），保留呼吸缩放。
- 接触阴影 → 保持径向淡墨，但边缘加 2–3 笔"墨迹飞溅"（不规则小墨点）。

### D. 人流系统（小人/流动线/计数牌）
- 小人：身体线条加粗到 3.5px；随机 30% 概率画"双圈头"变体；脚下加 1 个小椭圆淡墨影。
- 流动线：点改**小箭头贴图**（沿贝塞尔路径指向门口），方向随运动翻转。
- 计数牌：边框改一圈"虚线手绘"，数字加随机旋转角 ±0.08rad（已有）＋偶发"描边错位"（stroke 偏移 1px 的复绘）。

### E. 开屏引导叙事（intro.js / intro.css）—— 碎片语言主战场
- 段一「迷茫」12 片三角形 → 12 片**混合多边形**（三角/四边/五边），漂浮加自旋 ±8°；聚合问号时碎片带"墨迹拖尾"（快速缩小的 2 个影子片）。
- 段二「探索」四校区轮廓 → **每校区由 5–7 片多边形碎纸拼成**（Species 式拼贴地图），生长动画保留 dash 描边，但先"碎片聚合"再"描边生长"。
- 段三「掌控」3D 卡片 → 卡片边缘改**撕纸边**（clip-path 不规则 8 边形），折起时每片纸角微翘（rotateX 带 ±2° 随机）；碎裂粒子 → 五边形碎纸（带墨线边），重组立方改**碎纸多面体**（六面各由 2 片拼成）。
- 段四「成长」徽章 → 徽章加蜡笔描边圈 + 胶带角；证书边框改双层手绘抖线 + 角上星形胶带。

### F. 首页 8 层视差（可建模的插图层）
- 手绘建筑线稿 SVG → 升级为**碎纸拼贴建筑**：每栋 = 主体多边形 + 屋顶三角形 + 2–3 个窗色块（四色马克笔），拼缝 2px 纸底透出；远层（教学楼/图书馆/食堂三栋）低透明度 0.45–0.6。
- 云层改 makemepulse 式椭圆纸云 ×2。
- 纸屑层加 1–2 片"撕下来的纸条"（细长多边形，微旋转）。

### G. 数据洞察抽屉（力导向图 SVG，风格统一）
- 节点圆 → **手绘双圈 + 碎片内芯**：外圈墨线不闭合（留 15° 缺口），内部 3 片三角碎片拼圆。
- 连线虚线 → 加"箭头小墨点"在流动方向端；跨校区星标保持。
- 点击碎裂 → 碎片数 6 → 8，碎片为混合多边形（现为四边形 clip-path，可混入三角）。

### H. 地图 3D 层（高德 Loca，只能优化贴图与配色）
- 呼吸点贴图 → **碎片扩散环**：光晕从 1 片碎纸分裂为 3 片飞散的碎纸（Canvas 帧序列），替代径向渐晕。
- 事务链虚线 → 加"终点墨点"贴图；六链颜色保持不变（已定色板）。
- 楼块（AMap.Buildings）→ 主题色墙/顶保持，不越权改高德渲染。

### I. 天气粒子（scene-fx.js）
- 雨滴 → 细长四边形（2×8px 圆头墨线）+ 落地溅起 1 个小墨点。
- 雪花 → 6 角星贴图（替代圆点），数量 ≤ 80 不变。
- 闪电 → 折线改为 3 段**锯齿手绘折线**。

## 四、硬约束（不可违反）

1. 功能与交互零改动：kind 映射、状态阈值（60/85）、打开方式、剖面/爆星/手势逻辑全部保持。
2. 性能预算：单建筑 ≤ 3000 三角形、部件 ≤ 40；场景碎片总数 ≤ 50；小人粒子 ≤ 60（低端机 0）；DPR ≤ 2；单一渲染循环。
3. 降级链保持：低端机关阴影/粒子/爆星；prefers-reduced-motion 全部动画瞬时；WebGL 不可用则 3D 按钮置灰。
4. 色板锁定：只用四色马克笔 + 六色撞色板 + 墨色 #2B2B2B/#2B2620 + 纸底 #FEFBF6/--bg；不引入新色相。
5. 零外部资源：所有贴图程序化 Canvas 生成；Three.js r147 本地 vendor；file:// 直开可用。
6. 确定性：每个模型的随机参数仍以 spotId 为种子，同一建筑每次打开外观一致。
7. 不破坏：高德 logo 合规、64 点位 id、localStorage 前缀 zxsj66_、AI 安全链路。

## 五、交付物与验收标准

交付：按 A–I 逐项给出**修改后的建模方案**（部件表 + 几何参数 + 颜色 + 动画参数），并标注与现版差异。

验收（逐项打勾）：
- [ ] 五类建筑 + 三类通用建筑全部通过"碎片拼合 + 墨线 + 平涂"三规则检查
- [ ] 每个场景至少 1 处 makemepulse 活物感动画（呼吸/漂浮/跟随）
- [ ] 每个场景至少 1 处 Species 式聚合/碎裂
- [ ] 三角形预算、碎片数、粒子数在红线内
- [ ] 低端机 / reduced-motion 降级路径未破坏
- [ ] 全站四色马克笔色板一致，无新增色相
- [ ] 同一 spotId 重复打开模型外观一致（种子确定性）
- [ ] file:// 双击 index.html 直接可看，无报错
